# Selenium

 Установите JDK. Потребуется Java Development Kit версии 8 или выше. Проверьте установку командами java -version и javac -version. Добавьте зависимость в проект. Если вы используете систему сборки (Maven или Gradle), добавьте зависимость на Selenium в файл конфигурации проекта. - Для Maven: в pom.xml добавьте элемент <dependency> с группой org.seleniumhq.selenium, артефактом selenium-java и нужной версией. - Для Gradle: в build.gradle добавьте строку implementation 'org.seleniumhq.selenium:selenium-java:4.15.0'.

# Intellij Idea

Перейдите на страницу загрузок JetBrains https://www.jetbrains.com/idea/download/ Выберите версию. Для старта отлично подойдёт  Community Edition - она бесплатна и покрывает базовые задачи.
Скачайте подходящий дистрибутив  под вашу  ОС. Для Windows это .exe, для macOS — .dmg, для Linux — архив (.tar.gz). Запустите скачанный файл и следуйте инструкциям мастера установки. - На Windows можно отметить опции: добавить ярлык на рабочий стол, связать расширение .java с открытием в IntelliJ IDEA, выбрать папку для ярлыков. На macOS просто перетащите скачанный .dmg-файл в папку «Программы». На Linux распакуйте архив и запустите установку командой ./idea.sh из каталога bin. Дождитесь завершения установки и нажмите «Готово».

# maven

Что нужно перед установкой Главное условие: на компьютере должен быть установлен JDK версии 8 или новее. Maven написан на Java, поэтому без JDK он не запустится. Проверьте в терминале/командной строке: - java --version — должна отобразиться информация о версии Java. - Также убедитесь, что переменная окружения JAVA_HOME правильно указывает на папку с JDK. Как установить Есть несколько путей — выбирайте под вашу задачу. - Вручную из архива. Скачайте бинарный архив (для Windows — .zip, для Linux/macOS — .tar.gz) с официальной страницы загрузки Maven (maven.apache.org/download.cgi). Распакуйте архив в удобную папку. Совет: выбирайте путь без пробелов, кириллицы и специальных символов. Внутри архива будет папка bin с исполняемыми файлами Maven. - Через пакетный менеджер. Это часто удобнее, особенно в Linux. В зависимости от дистрибутива команда будет разной: - Ubuntu/Debian: sudo apt install maven. - Fedora: sudo dnf install maven. macOS: brew install maven (с Homebrew). Windows: можно использовать Chocolatey или Scoop. 

# Jmeter
Cкачайте  Jmeter Перейдите на официальную страницу загрузки : jmeter.apache.org. В разделе Binaries выберите архив — он бывает в формате .zip (для Windows) или .tgz (для Linux/macOS). Важно: не берите архив из раздела Source — для запуска нужна именно бинарная сборка. Распакуйте архив У JMeter нет классического установщика — вы просто распаковываете скачанный архив в любую папку на вашем компьютере. Я советую выбирать путь без пробелов в названии (например, не «Program Files» в Windows) — так меньше шансов на ошибки при запуске. В распакованной папке найдите подпапку bin. В ней лежат скрипты для запуска: - Windows: запустите jmeter.bat. - Linux/macOS: запустите jmeter.sh. Если всё в порядке, откроется графический интерфейс — удобно для создания и отладки тестов.
